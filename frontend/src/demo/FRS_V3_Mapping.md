# Sub2API Demo 演示平台 —— FRS V3.0 需求对标表

本文档用于说明当前的 Demo 演示平台（`/frontend/src/demo` 目录）是如何覆盖与体现《AI模型API中转中台与应用平台_产品功能规格说明书与子项设计手册_V3.0.md》中所定义的核心需求的。

## 架构概览

Demo 平台采用了与 FRS V3.0 一致的**四级分层架构模型对齐**思路来组织页面结构：

1. **平台顶级控制层**：集成于原有的管理员后台菜单，并在官网首页入口处以“展开功能清单”的形式呈现（模块 2.1, 2.5, 2.6, 2.8 等）。
2. **渠道代理商控制层 (Agent)**：`/demo/agent/*` 路由。
3. **企业/组织租户控制层 (Tenant)**：`/demo/tenant/*` 路由。
4. **终端使用者 / API Key 层 (End User)**：`/demo/portal/*` (官网与网页对话) 以及 `/demo/desktop` (桌面端)。

---

## 模块对标详情

### 1. Engine A: 向量语义缓存与智能调度引擎 (核心亮点)
- **需求出处**: 核心业务引擎设定。
- **Demo 体现**: 
  - 在 **企业租户门户 (TenantDashboard.vue)** 的核心数据卡片中，展示了“语义缓存命中率”和“本月为您节省费用”。
  - 在 **网页对话机器人 (PortalChatbot.vue)** 聊天框顶部，展示了悬浮提示：“已启用语义缓存，重复问题将秒级响应并免扣费”。

### 2. Engine B: 多级穿透扣费与实时分账引擎 (核心亮点)
- **需求出处**: 核心业务引擎设定。
- **Demo 体现**:
  - 在 **官网定价页 (PortalPricing.vue)** 强调“多级穿透分账，精确到每一次请求”。
  - 在 **渠道代理门户 (AgentPricing.vue)** 中专门展示了“价格穿透说明”，解释了加价率与平台结算价的差额即为佣金收益。
  - 在 **渠道代理门户 (AgentPayouts.vue)** 中提供了“佣金与提现”的页面展示。

### 3. FRS 2.1 基础模型代理与聚合 (Platform)
- **需求出处**: 平台管理员配置各种模型的上游渠道。
- **Demo 体现**: 
  - 集成在 Home 页 DemoCenterSection.vue 的“系统管理员配置能力清单”中，点击即可路由至真实的后端模型配置页面。

### 4. FRS 2.2 跨平台客户端 (终端用户)
- **需求出处**: Windows/macOS/iOS/Android 客户端功能。
- **Demo 体现**: 
  - 通过 `/demo/desktop` (**DesktopClient.vue**) 页面进行了 Web 层的仿真，模拟了 Windows 的无边框窗体、沉浸式对话、拖拽交互以及侧边栏历史会话等核心功能 (2.2.1 ~ 2.2.6)。

### 5. FRS 2.3 网页版对话机器人 (终端用户)
- **需求出处**: 网页版 Chatbot。
- **Demo 体现**: 
  - 通过 `/demo/portal/chatbot` (**PortalChatbot.vue**) 实现了全屏的沉浸式对话界面，支持模型切换、历史记录展示和多模态上传界面 (2.3.1 ~ 2.3.7)。

### 6. FRS 2.4 官方门户网站 (终端用户 / 游客)
- **需求出处**: 官网主页、定价、模型广场、文档等。
- **Demo 体现**: 
  - **PortalHome.vue**: 官网主页，核心特性宣发 (2.4.1)。
  - **PortalModels.vue**: 模型广场，展示模型能力与价格 (2.4.2)。
  - **PortalDocs.vue**: 文档中心，三步快速接入指南 (2.4.3)。
  - **PortalPricing.vue**: 定价方案，包含企业订阅及代理分销引导 (2.4.4)。
  - **PortalAbout.vue**: 关于我们，联系方式与愿景 (2.4.5)。

### 7. FRS 2.5 流量分发与调度机制 (Platform)
- **需求出处**: 轮询、负载均衡、高可用。
- **Demo 体现**:
  - Home 页平台运营管理员清单中体现。
  - **AgentPools.vue** (代理商专属号池) 中展示了“并发上限”和“负载均衡策略: 自适应延迟轮询”。

### 8. FRS 2.6 财务账单系统 (Tenant / Platform)
- **需求出处**: 充值、对账、发票等。
- **Demo 体现**:
  - **TenantBilling.vue** (企业租户 - 财务与账单) 页面展示了余额预警、计费周期报表、模型费用分布明细以及 PDF 账单下载等功能。

### 9. FRS 2.7 账号体系与租户管理 (Tenant)
- **需求出处**: 企业级多租户、RBAC、安全策略。
- **Demo 体现**:
  - **TenantDashboard.vue**: 租户控制台总览，额度分布与审计日志 (2.7.2)。
  - **TenantKeys.vue**: 组织级 API Key 管理，可细粒度控制模型与额度 (2.7.4)。
  - **TenantSecurity.vue**: 登录与安全，2FA 强制开启、SSO 配置、IP 白名单 (2.7.5)。
  - **TenantEmployees.vue**: 员工与子账号管理，角色分配，额度划拨 (2.7.6)。

### 10. FRS 2.10 渠道代理与分销系统 (Agent)
- **需求出处**: 代理商专属管理后台。
- **Demo 体现**:
  - **AgentDashboard.vue**: 代理概览，专属邀请链接与返佣阶梯规则 (2.10.1, 2.10.4)。
  - **AgentPools.vue**: 专属物理隔离号池分配与运行状态 (2.10.2)。
  - **AgentPricing.vue**: 专属费率加价配置，按全局与按模型覆盖 (2.10.3)。
  - **AgentClients.vue**: 下级客户（企业/个人）管理与收益转化漏斗 (2.10.5)。
  - **AgentPayouts.vue**: 佣金收益报表及银行提现申请 (2.10.6)。

---
**说明**：本 Demo 平台专注于向潜在客户或投资人做直观的前端交互展示，底层数据的交互皆由 Pinia store (`useDemoStore.ts`) 在内存中进行模拟驱动，无需复杂的后端接口对接即可顺畅体验 FRS V3.0 描述的产品价值。
