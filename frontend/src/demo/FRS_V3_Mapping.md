# Sub2API Demo 演示平台 —— FRS V3.4 需求对标表

本文档用于说明当前的 Demo 演示平台（`/frontend/src/demo` 目录）是如何覆盖与体现《AI模型API中转中台与应用平台_产品功能规格说明书与子项设计手册_V3.4.md》中所定义的核心需求的。

## 架构概览

Demo 平台采用了与 FRS V3.4 一致的**四级分层架构模型对齐**思路来组织页面结构：

1. **平台顶级控制层**：集成于原有的管理员后台菜单，并在官网首页入口处以"展开功能清单"的形式呈现（模块 2.1, 2.5, 2.6, 2.8 等）。
2. **渠道代理商控制层 (Agent)**：`/demo/agent/*` 路由。
3. **企业/组织租户控制层 (Tenant)**：`/demo/tenant/*` 路由。
4. **终端使用者 / API Key 层 (End User)**：`/demo/portal/*` (官网与网页对话) 以及 `/demo/desktop` (桌面端)。

## 模块对标详情

### 1. 安全敏感词合规护栏 (核心亮点)
- **需求出处**: V3.4 模块 2.5.1 安全敏感词护栏（输入/输出双向实时拦截，对接网信办标准词库）。
- **Demo 体现**: 
  - 在 **企业租户门户 (TenantDashboard.vue)** 的核心数据卡片中，展示了"安全敏感词护栏"合规通过率 99.97% 和本月拦截违规请求次数。
  - 在 **官网首页 (PortalHome.vue)** 核心特性中展示了"安全合规与内容护栏"。
  - 在 **官网 Footer (PortalLayout.vue)** 中展示了"安全敏感词合规护栏"。
  - 在 **平台管理员功能清单 (useDemoStore.ts)** 中新增了 2.5.1 安全敏感词护栏子项。

### 2. Engine B: 多级穿透扣费与实时分账引擎 (核心亮点)
- **需求出处**: 核心业务引擎设定。
- **Demo 体现**:
  - 在 **官网定价页 (PortalPricing.vue)** 强调"多级穿透分账，精确到每一次请求"。
  - 在 **渠道代理门户 (AgentPricing.vue)** 中专门展示了"价格穿透说明"，解释了加价率与平台结算价的差额即为代理净利润。
  - 在 **渠道代理门户 (AgentPayouts.vue)** 中提供了"双向对账单"展示（平台-代理 & 代理-下游客户）。

### 3. FRS 2.1 中转站中台 (Platform, 5子项, 3.5人日)
- **需求出处**: 平台核心网关、API 协议转换、熔断限流。
- **Demo 体现**: 
  - 集成在 Home 页 DemoCenterSection.vue 的"系统管理员配置能力清单"中（2.1.1~2.1.5），点击即可路由至真实的后端配置页面。

### 4. FRS 2.2 一键部署客户端 (终端用户, 7子项, 32.5人日)
- **需求出处**: Win/Mac 双端桌面客户端及聊天客户端。
- **Demo 体现**: 
  - 通过 `/demo/desktop` (**DesktopClient.vue**) 页面进行了 Web 层的仿真，模拟了 Windows 的无边框窗体、系统托盘、多线路切换、一键环境注入、延迟测速大盘、静默更新及日志抓包等核心功能 (2.2.1 ~ 2.2.6)。
  - **V3.4 新增 2.2.7 聊天机器人客户端**：在桌面客户端中新增了"🤖 聊天机器人"Tab，内嵌完整的对话界面，支持模型选择、Prompt 预设标签与多轮对话。

### 5. FRS 2.3 网页版对话机器人 (终端用户, 7子项, 23.0人日)
- **需求出处**: 网页版 SaaS Chatbot。
- **Demo 体现**: 
  - 通过 `/demo/portal/chatbot` (**PortalChatbot.vue**) 实现了全屏的沉浸式对话界面，支持模型切换、历史记录展示和多模态上传界面 (2.3.1 ~ 2.3.7)。

### 6. FRS 2.4 官网门户与文档中心 (终端用户 / 游客, 5子项, 9.0人日)
- **需求出处**: 品牌官网、模型广场、文档中心、定价对比矩阵。
- **Demo 体现**: 
  - **PortalHome.vue**: 官网首页，核心特性宣发 (2.4.1)。
  - **PortalModels.vue**: 模型广场，展示模型能力与价格 (2.4.2, V3.4 升级为独立数据库方案)。
  - **PortalDocs.vue**: 文档中心，三步快速接入指南 (2.4.3)。
  - **PortalPricing.vue**: 定价方案，包含企业订阅及代理分销引导 (2.4.4)。
  - **PortalAbout.vue**: 关于我们，联系方式与愿景 (2.4.5)。

### 7. FRS 2.5 核心模型网关能力补全 (Platform, 1子项, 20.0人日)
- **需求出处**: V3.4 安全合规与敏感词拦截（注意：V3.0 的智能调度/亲和路由/语义缓存/重试队列已在 V3.4 中删除）。
- **Demo 体现**:
  - **AdminSensitiveWords.vue**: 独立 DEMO 页面 (`/demo/admin/sensitive-words`)，包含三个 Tab：
    - Tab 1: **词库规则管理** — 展示网信办标准库 + 自定义规则，支持热增加/删除、按分类筛选、开关启停
    - Tab 2: **安全审计日志** — 实时展示输入/输出双向拦截记录
    - Tab 3: **护栏配置** — 总开关、输入/输出方向独立开关、严格模式、词库来源同步配置、Webhook 通知
  - TenantDashboard 核心数据卡片中展示合规拦截率 99.97%。
  - 平台管理员功能清单（DemoCenterSection）中 2.5.1 子项可点击直达 DEMO 页面。

### 8. FRS 2.6 账单与充值系统 (Tenant / Platform, 6子项, 14.5人日)
- **需求出处**: Token级穿透扣费、账单报表、充值对接。
- **Demo 体现**:
  - **TenantBilling.vue** (企业租户 - 财务与账单) 页面展示了余额预警、计费周期报表、模型费用分布明细以及 PDF 账单下载等功能。

### 9. FRS 2.7 账号与权限体系 (Tenant, 7子项, 40.5人日)
- **需求出处**: 四级多租户、RBAC、2FA、子账号、专属门户。
- **Demo 体现**:
  - **TenantDashboard.vue**: 租户控制台总览，额度分布与审计日志 (2.7.1~2.7.2)。
  - **TenantKeys.vue**: 组织级 API Key 管理 (2.7.4)。
  - **TenantSecurity.vue**: 登录安全与 2FA (2.7.5)。
  - **TenantEmployees.vue**: 员工与子账号管理 (2.7.6)。
  - **V3.4 新增 TenantUserPortal.vue**: 用户专属门户 (2.7.7)，以员工/普通用户视角展示个人 Key 管理、用量明细、可用模型列表。

### 10. FRS 2.8 上游号池渠道管理 (Platform, 6子项, 4.5人日)
- **需求出处**: 渠道接入、号池管理、监控大盘、告警。
- **Demo 体现**:
  - 平台管理员功能清单中展示 2.8.1~2.8.6，直接链接至真实后端管理页面。

### 11. FRS 2.10 下游代理管理系统 (Agent, 6子项, 25.0人日)
- **需求出处**: 代理商专属管理后台。
- **Demo 体现**:
  - **AgentDashboard.vue**: 代理概览，专属邀请链接与阶梯规则 (2.10.1, 2.10.4)。
  - **AgentPools.vue**: 专属物理隔离号池分配与运行状态 (2.10.2)。
  - **AgentPricing.vue**: 专属费率与多维度分层加价矩阵 (2.10.3)。支持代理商针对【直营个人用户】与【下级企业租户】分别建立独立加价规则，并结合不同【上游专属号池与底价】进行多级穿透定价与实时单价利润测算。
  - **AgentClients.vue / AgentDirectUsers.vue**: 下级客户管理与直营用户 (2.10.5)。
  - **V3.4 重写 AgentPayouts.vue**: 从"佣金提现"完全重写为"结算与双向对账"（2.10.6），包含两个 Tab 视图：
    - Tab 1: **平台运营方 vs 代理商对账单**（按平台底价与代理出资额汇总对账）
    - Tab 2: **代理商 vs 下游企业租户/用户对账单**（按代理独立加价倍率与下游实际消费额汇总对账）
